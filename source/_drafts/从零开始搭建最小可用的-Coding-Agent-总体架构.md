# 前言
各类不同细分场景的 Agent 目前已经是大家日常工作和生活中的常用工具，笔者在很长一段时间内将这类工具视为黑盒，个中原理仅仅通过各类零散的技术文章浅尝辄止。希望通过自己从头实现一个最小可用的 Coding Agent 来理解这个问题：如何通过工程手段让一个只会做 “猜下一个字游戏” 的 LLM 变成一个万能的许愿机，只要跟他说话就能实现你的愿望。
